# ПЛАН РАЗРАБОТКИ WEB-ВЕРСИИ CUBING ROBOT v2

## ОБЗОР ПРОЕКТА

Веб-версия Cubing Robot представляет собой Flask-приложение, которое заменяет десктопное PyQt6 приложение и запускается на одноплатном компьютере Orange Pi Zero 3. Сервер обеспечивает управление роботом через веб-интерфейс, автоматическое управление WiFi подключениями и все функции оригинального десктопного приложения.

## АРХИТЕКТУРА СИСТЕМЫ

### Технологический стек:
- **Backend**: Python 3.13 + Flask
- **Frontend**: HTML5, CSS3, JavaScript (без фреймворков)
- **База данных**: SQLite (существующие базы)
- **Коммуникация с роботом**: Serial (Arduino Mega 2560)
- **Камеры**: OpenCV + USB камеры (пока только UI)
- **Сетевые настройки**: NetworkManager через Python
- **Интернационализация**: Flask-Babel (русский/английский)

### Режимы работы сети:
1. **AP Mode** (Access Point): Orange Pi создает собственную сеть "CubingRobot_AP"
2. **STA Mode** (Station): Orange Pi подключается к внешней WiFi сети
3. **Автопереключение**: При запуске проверяет доступные сохраненные сети

## ОСОБЕННОСТИ РАЗВЕРТЫВАНИЯ

1. **Автозапуск**: systemd сервис для автоматического запуска при загрузке Orange Pi
2. **WiFi инициализация**: Скрипт проверки и подключения к сохраненным сетям при запуске
3. **Статический порт Arduino**: Arduino всегда подключен к одному USB порту
4. **Права доступа**: Права для работы с сетевыми интерфейсами и USB устройствами

## БЕЗОПАСНОСТЬ

1. **Локальная сеть**: Сервер работает только в локальной сети
2. **Опциональная аутентификация**: По желанию пользователя
3. **Блокировка робота**: Защита от одновременных команд
4. **Валидация данных**: Проверка всех входящих данных

Этот план обеспечивает полную функциональность десктопной версии в веб-формате с дополнительными возможностями управления WiFi и системными настройками.
