Отличия Cubing Robot v2 от Cubing Robot v1

1. В робота будет добавлен одноплатный компьютер Orange Pi Zero 3 (4GB оперативной памяти)
   У компьютера есть 3 USB 2.0 порта, через которые к компьюетру подключены 2 модуля камеры 
   NEOCoolcam 4MP, а также  Arduino Mega 2560. То есть теперь Arduino подключается не к внешнему ПК 
   пользователя, а ко ввнутренней Orange Pi. Arduino всегда статически подключен к одному и тому же порту Orange Pi.
2. Управляющая программа будет представлена не десктопным приложением, а WEB-интерфейсом (сервером),
   который будет запускаться на Orange Pi при включении устройства. 
3. Будет разработана следующая логика управления устройством:
    а. Пользователь включает устройство
    б. При появлении питания Orange Pi запускает Python-файл с сервером, через который будет осуществляться
       управление устройством. 
    в. Изначально Orangу Pi сама выступает точкой доступа, и сервер запускается на локальной сети
       Orange Pi. Пользователь должен подключить своё устройство к Orange Pi по WiFi, после чего заходит
       на сервер. Через WEB-интерфейс пользователь может подключить робота к любой доступной сети 
       (например, к домашнему роутеру), и после этого робот должен запомнить эту сеть, и в последствии 
       при включении устройства робот должен пытаться подключиться к этой сети. При неудачной попытке
       (например, если робота включают в другом месте) Orange Pi снова сама должна становиться точкой доступа.
    г. После настройки WiFi и подключения к серверу робота пользователь может перейти к управлению устройством:
       сервер должен быть разбит на страницы (как и десктопное приложение), на каждой из которых будет соответствующая 
       функция управления: сборка кубика, скрамбл, создание узоров, непосредственное управление и т.д. (см. ветку Desktop).
       При отправлении соответствующей команды на сервер Orange Pi, компьютер создает последовательность действий робота (как 
       и в десктопной версии), и через Serial-порт последовательно передаёт их Arduino. Код на Arduino при этом остаётся тем же.
