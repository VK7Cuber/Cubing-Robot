В окне "Скрамбл" у меня есть две вкладки, сменяющие друг друга через Qstackedwidget. Я хочу добавить третью вкладку с названием "Соревновательный скрамбл", в этой вкладке будут следующие объекты: 5 полей для ввода скрамблов, расположенные друг под другом. Это просто поля для ввода текста, куда пользователь будет вводить скрамблы кубика Рубика. Слева от каждого поля должна быть расположена QRadioButton, благодаря которому пользователь сможет выбрать, какой скрамл использовать прямо сейчас.  Под ними (как и на всех вкладках) поле "Установите скорость вращения моторов", а ниже две кнопки: "Проверить скрамблы" и "Начать скрамбл". 

При нажатии на кнопку "Проверить скрамблы" приложение должно проверить, во всех ли заполненных полях введены верные скрамблы, нет ли неправильных букв (список правильных букв можешь посмотреть в словаре encoding в файле "Devices\Arduino\arduino_connection.py"). Программа должна проверять только заполненные поля. При ошибке в каком-то из введённых скрамблов поле, в которое ввели этот скрамбл, должн подсветится красным, а внизу (в Statusbar) должно быть выведено сообщение о  том, в каком скрамбле допущена ошибка и что за ошибка. Код для проверки правильности скрамбла пиши в отдельном файле в папке Other.

При нажатии на кнопку "Начать скрамбл" приложение должно отправить роботу соответствующий скрамбл. Перед отправкой также вызови функцию проверки скрамбла, чтобы не отправить что-то неравильное. Используй существующую функцию отправки, она называется "send_message()" и находится в файле "Devices\Arduino\arduino_connection.py". Предварительно установи выбранную скорость вращения моторов через функцию "set_motors_speed()", находящуюся в том же файле. С правильным использованием этих функций ознакомься, прочитав все остальные файлы проекта, особенно файлы в папке Windows.
